1、can数据接收丢失问题

2024年7月30日
查找半天，发现是基于板卡调试，另一路的can通道没有借外设，产生通讯故障，
can通道在不停的初始化，导致本通道can数据有丢失。
LPC1778的两路can在初始化是互相影响。

2、Jlink下载不了程序

2024年8月14日
jlink使用7.20，频率200k，中试的硬件jlink可以下载程序了。
不确定是那里的问题，可能板卡也得重新上电。
后来跟换第一版板卡好了。是因为复位芯片的原因导致下载不了程序。

3、CAN发送文件

OTA调试，修改以下代码。问题不是以下代码的问题，是应该can盒经过usbhub转换的问题，can盒直接接电脑测试OK。
pCAN->CMR = 0x23; //不重发
if (pCAN->GSR & 0x00C0) { //总线出错或关闭
s32_can_init(1, e_can1_baud);
}
t_can1_tx_msg.u32_read_index = t_can1_tx_msg.u32_write_index = 0;
