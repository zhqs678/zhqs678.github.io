gdb命令用于coredump分析

Categories： Tags：

x 用来以指定格式查看内存，和在程序中的数值类型没有关系。
p 打印变量的值和地址。
(gdb) p &a
display 相当于自动输出的 x 或 print。display 会在每次暂停的时候输出表达式的值。display 会根据指定的模式自动选择使用 x 或是 print：
如果使用 ‘i’ 或 ‘s’ 格式, 或者指定了 unit size，会使用 x 输出值，其他情况下使用 print。
display expr
display/f expr
display/t addr

在GDB中查看全局变量

在使用GDB调试程序时，查看全局变量是一个常见的需求。GDB提供了多种命令来查看不同类型的变量，包括全局变量、局部变量和静态变量。

查看全局变量

要查看当前程序中的所有全局变量和静态变量，可以使用以下命令：
info variables
这个命令会列出所有全局变量和静态变量，包括它们的类型和地址

查看局部变量

如果你想查看当前堆栈帧中的局部变量，可以使用以下命令：
info locals
这个命令会显示当前函数中的所有局部变量及其值

查看函数参数

要查看当前堆栈帧中的函数参数，可以使用以下命令：
info args
这个命令会列出当前函数的所有参数及其值

使用print命令查看变量

除了上述命令外，你还可以使用print命令（简写为p）来查看特定变量的值。print命令的格式如下：
print
其中，是你想要查看的变量或表达式。例如，要查看变量num的值，可以使用以下命令：

(gdb) print num
你还可以使用不同的格式来显示变量的值，例如以十六进制格式显示：

(gdb) print/x num
这会将变量num的值以十六进制格式输出

自动显示变量值

如果你希望在每次程序暂停时自动显示某些变量的值，可以使用display命令。display命令的格式如下：
display
例如，要在每次程序暂停时自动显示变量num的值，可以使用以下命令：
(gdb) display num
这样，每次程序暂停时，GDB都会自动显示变量num的当前值
通过这些命令，你可以方便地在GDB中查看全局变量、局部变量和函数参数的值，从而更好地调试你的程序。

输出格式

GDB会根据变量的类型输出变量的值，但你也可以自定义输出格式。例如，使用/x可以按十六进制格式显示变量：
(gdb) p/x num
这会将变量num的值以十六进制格式输出
通过这些命令，你可以方便地在GDB中查看全局变量、局部变量和函数参数的值，从而更好地调试你的程序。
